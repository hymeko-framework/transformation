\section{Goal \& scope}
Re-pin \texttt{hymeko/transformation} (\texttt{hymeko\_query}, \texttt{hymeko\_formats},
\texttt{hymeko\_emitter}) from \texttt{hymeko\_core@15223bcd} to the canonical
\texttt{hymeko\_core@5fe2c88}, so the whole Cargo graph carries \textbf{exactly one}
\texttt{hymeko\_core}. No transform \emph{semantics} change; query/transform/emit output stays
\textbf{byte-identical} where the contract requires it. No \texttt{hymeko\_core} production edit.
No second IR / DTO / bridge created. Branch \texttt{feat/transformation-current-canonical-core}.

\section{Why it was blocked, and why it is now feasible}
core@main replaced the three public \texttt{decl\_to\_\{node,edge,arc\}: Vec<Option<Id>>} maps
with a \emph{private} 8-byte dispatch slot (\texttt{decl\_to\_record}, ``option D'', 2026-08-31).
Transformation writes those maps directly at \textbf{$\approx$24 sites}. core@5fe2c88 exposes the
matching \textbf{public construction seam}: \texttt{push\_decl(DeclNode)->DeclId} (arena $+$ NONE
slot) and public \texttt{bind\_\{node,edge,arc\}\_decl(d, id)->Result<(),DispatchError>}. Every
write site is \emph{fresh construction} (a local \texttt{push\_decl} helper $+$ record binds), not
in-place topology mutation, so it maps \textbf{1:1} to the public API. Audit bottom line: the
migration needs \textbf{no missing core mutation API} and \textbf{no HARD STOP}.

\section{Test strategy}

\texttt{.hymeko} + URDF/SDF/MJCF/DOT/Mermaid goldens; canonical hash; entity cardinalities; error

transform commit, emitter reading another IR) each caught by a named test.

\section{Risk anticipation}
\begin{itemize}[nosep]
  \item \textbf{Worst case:} a deterministically-generated $\ge 10^5$-incidence source through
        \texttt{compile}$\to$\texttt{transform}$\to$\texttt{emit}; the migrated construction path
        must stay $O(\text{nnz})$ and byte-identical.
  \item \textbf{Contract:} \texttt{bind\_*\_decl} returns \texttt{Result}; the old field write could
        not fail. The migration must handle/propagate \texttt{DispatchError} (index-overflow /
        double-bind) rather than \texttt{unwrap} silently at the $10^5$ scale — but a bind that the
        old code did unconditionally is provably first-and-only, so a documented invariant +
        \texttt{expect} is acceptable where proven, else propagate.
  \item \textbf{Two core versions:} \texttt{cargo tree} must show exactly one \texttt{hymeko\_core};
        any second (via a stale transitive pin) is a build-breaking finding.
  \item \textbf{Dirty user checkout:} the user is actively on \texttt{feat/geometry-\dots} with new
        \texttt{hymeko\_dynamics}/\texttt{hymeko\_optimize} crates. Work only in the clone
        \texttt{/d/hnnwork/transformation}; never touch the user checkout.
\end{itemize}
