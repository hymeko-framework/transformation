\paragraph{HHO choices} Sequential in-place proposals and population means; leader updated only by population scans. Every objective call, including repeated parent comparisons, is charged. Repair every evaluator input by componentwise clamp; store the repaired accepted trial. Pending unconditional proposals are repaired at the next scan. Python binary64/Random, Mantegna beta=1.5 without extra scale. Zero normal divisor/nonfinite proposals fail explicitly. Return host best-ever, with last-scored slot snapshots separately retained. Stop before B+1, including mid-comparison; no unscored score fabrication.
\paragraph{Clock control} Single implementation, two named settings. Iteration clock uses T=ceil(B/N), factor=2*(1-t/T). Evaluation clock uses factor=2*(1-(count-N)/(B-N)) at the end of each population scan and freezes it for that update sweep. No update at B=N. Source RNG order and conditional branches are documented; no MATLAB bitwise-RNG equivalence claim.
